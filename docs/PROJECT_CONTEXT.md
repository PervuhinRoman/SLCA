# PROJECT_CONTEXT — StudentLedger

## 1. Проект

**Название:** StudentLedger  
**Тип:** учебное веб-приложение  
**Назначение:** информационная система учёта успеваемости студентов.

## 2. Основные роли

### student
- проходит аутентификацию;
- просматривает собственные персональные сведения;
- просматривает собственные оценки;
- просматривает учебные планы;
- не изменяет сведения о студентах, учебные планы, оценки и учётные записи.

### teacher
- проходит аутентификацию;
- просматривает сведения о студентах и учебные планы;
- просматривает, добавляет и изменяет оценки только по дисциплинам, закреплённым за его учётной записью;
- не управляет учётными записями и ролями.

### administrator
- управляет пользователями и ролями;
- управляет сведениями о студентах;
- управляет дисциплинами и учебными планами;
- имеет доступ ко всем записям журнала успеваемости;
- имеет доступ к журналу аудита;
- может блокировать учётные записи и инициировать сброс пароля.

## 3. Основные сущности

- `User`
