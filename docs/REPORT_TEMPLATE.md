# REPORT_TEMPLATE

Использовать как инструкцию агенту при создании отчёта каждой ЛР.

## Основное правило

Отчёт создаётся **только после** выполнения Agent DoD и Human DoD.

Нельзя:
- придумывать IP, команды или результаты;
- вставлять вымышленные скриншоты;
- утверждать, что pipeline/VM/container работает без evidence.

## Оформление

Ориентироваться на оформление актуального отчёта ЛР1:
- сохранять академический стиль;
- единообразные заголовки;
- оглавление;
- подписи к рисункам;
- нумерованные таблицы при необходимости;
- реальные команды и скриншоты.

## Рекомендуемая структура

1. Титульный лист
2. Оглавление
3. Цель работы
4. Используемые средства
5. Ход выполнения работы
6. Результаты проверок
7. Ответы на вопросы к защите (если есть в методичке)
8. Заключение

## Для каждого пункта задания методички

В отчёте должно быть:
- что требовалось;
- что сделано;
- команда/конфигурация;
- результат;
- ссылка на рисунок/скриншот.

## Перед финализацией

Проверить:
- все пункты задания покрыты;
- screenshots подписаны;
- команды соответствуют реальному проекту;
- названия окружений, веток, сервисов единообразны;
- нет противоречий с ТЗ;
- нет секретов.
