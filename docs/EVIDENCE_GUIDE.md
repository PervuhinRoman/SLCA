# EVIDENCE_GUIDE

## Назначение

Evidence — фактические подтверждения выполнения лабораторной работы.

## Правила

- Один screenshot должен подтверждать конкретный факт.
- Имя файла начинается с номера: `01-...`, `02-...`.
- Не хранить на скриншотах пароли, токены, secret keys.
- Если секрет попал на screenshot — скрыть его до добавления в отчёт.
- Для CLI сохранять команду и видимый результат.
- Для TeamCity сохранять название build configuration, branch и статус.
- Для Docker сохранять `docker ps` / compose status.
- Для БД сохранять только безопасную информацию.

## Формат handoff от человека

Для каждой ЛР человек передаёт агенту:

```text
Environment:
Commands executed:
Result:
Problems:
Screenshots:
- ...
- ...
```

Агент не должен считать ручной этап выполненным без этих данных.
